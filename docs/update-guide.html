2 자기소개 수정 — aboutme.md

위쪽 --- 사이(front matter)는 페이지 제목/부제, 그 아래가 본문입니다.

aboutme.md 
---
layout: page
title: About Me
subtitle: 자기소개
---

안녕하세요, **HyungminAn** 입니다. ...

### 관심 분야
- ...
  • <!-- TODO ... --> 로 표시된 부분을 실제 내용으로 바꾸세요.
  • 프로필 사진: assets/img/avatar-icon.png 교체 또는 _config.yml 의 avatar: 경로 변경.

3 연락처 수정

3-1. Contact 페이지 본문

contact.md 
- <i class="fas fa-envelope"></i> **Email**: [me@example.com](mailto:me@example.com)
- <i class="fab fa-github"></i> **GitHub**: [github.com/HyungminAn](https://github.com/HyungminAn)

아이콘은 Font Awesome 이름을 씁니다 (fas fa-…, fab fa-…).

3-2. 모든 페이지 하단(footer) 아이콘

_config.yml 
social-network-links:
  email: "me@example.com"    # 주석(#)을 지우면 footer 에 표시됨
  rss: true
  github: HyungminAn
#  linkedin: your-id
#  google-scholar: your-id
이메일은 현재 예시 값(your.email@example.com)이고 footer 에서는 주석 처리되어 있습니다. 공개해도 되는 주소로 바꿔 주세요.

4 게시판에 새 글 쓰기 — _posts/

4-1. 파일 만들기

_posts/ 에 YYYY-MM-DD-영문-제목.md 형식으로 파일을 만듭니다.

_posts/2026-11-01-my-first-paper-review.md
  • 날짜가 파일명에 꼭 있어야 합니다.
  • 제목 부분이 URL 이 되므로 영문/숫자/하이픈을 권장합니다.
  • 미래 날짜의 글은 기본적으로 빌드되지 않습니다.

4-2. Front matter 작성

---
title: 논문 리뷰 - Attention Is All You Need
subtitle: Transformer 정리            # 선택
category: research                    # 게시판 토픽 id (필수)
tags: [paper, nlp]                    # 선택 — /tags 페이지에 모임
cover-img: /assets/img/path.jpg       # 선택 — 상단 큰 이미지
thumbnail-img: /assets/img/thumb.png  # 선택 — 목록 썸네일
mathjax: true                         # 선택 — 수식 사용 시
---

본문은 Markdown 으로 작성합니다.
키설명
category어떤 게시판(토픽)에 올라갈지. research / dev / daily 중 하나
tags토픽과 별개의 키워드. 여러 개 가능
layout생략 가능 (글은 자동으로 post)

4-3. 본문 팁

  • 이미지: assets/img/ 에 넣고 ![설명](/assets/img/파일명.png)
  • 코드 블록: ```python … ```
  • 강조 박스: 문단 바로 위에 {: .box-note} (.box-warning, .box-error, .box-success)
  • 예시 글: _posts/2026-10-24-markdown-cheatsheet.md

4-4. 글 수정 / 삭제

  • 수정: 해당 .md 파일을 고치고 push
  • 삭제: 해당 .md 파일을 지우고 push
  • 예시 글 2개(2026-10-24-markdown-cheatsheet.md, 2026-10-25-welcome.md)는 지워도 됩니다.

5 게시판 토픽 추가 / 변경

예: paper(논문) 토픽 추가 — 3군데를 수정합니다.

  1. _data/topics.yml 에 항목 추가 
    - id: paper
  name: 논문
  description: 읽은 논문 정리
  2. board/paper.md 파일 생성 
    ---
layout: topic
title: 논문
topic: paper
permalink: /board/paper/
---
  3. _config.yml 의 메뉴에 추가 
    navbar-links:
  About Me: "aboutme"
  Contact: "contact"
  Board:
    - 전체: "board"
    - 연구: "board/research"
    - 개발: "board/dev"
    - 일상: "board/daily"
    - 논문: "board/paper"     # 추가

이후 글에서 category: paper 를 쓰면 해당 게시판에 표시됩니다.

  • 이름만 변경: topics.yml 의 name, board/<id>.md 의 title, 메뉴 이름.
  • 토픽 삭제: 위 3군데에서 지우고, 그 토픽을 쓰던 글의 category 도 변경.
  • id 는 영문 소문자 (글의 category 값과 정확히 같아야 함).

7 로컬에서 미리보기 (선택)

Ruby 3.x 가 설치되어 있어야 합니다.

bundle install
bundle exec jekyll serve
# → http://localhost:4000 에서 확인

8 배포

GitHub Pages 가 저장소의 기본 브랜치를 자동으로 빌드합니다.

git add .
git commit -m "Add new post"
git push
  • 처음 한 번: 저장소 Settings → Pages → Build and deployment 에서 Source 를 Deploy from a branch, 브랜치를 master / / (root) 로 지정.
  • push 후 1~2분 뒤 https://hyungminan.github.io 에 반영됩니다.
  • GitHub 웹에서 파일을 직접 편집(연필 아이콘)하고 Commit 해도 똑같이 반영됩니다.
